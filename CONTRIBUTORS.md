# Bot67 contributors and credits

Bot67 is developed in [yileteoh/ip](https://github.com/yileteoh/ip) as a NUS CS2103T individual project.
See the repository's commit history for contributions to this version.

## Course template and tutorials

Bot67 began from the course's Duke individual-project template. Its JavaFX structure was adapted from the
JavaFX tutorial supplied with that project. References to Duke in these credits describe the project's origin;
the application itself is named Bot67.

The original template credited these contributors; their attribution is retained here:

## Images

`src/main/resources/images/Background.png`, `Bot67.png`, and `User.png` are third-party images found through
Google Images. Their original source URLs, authors, and licence details were not retained. Reuse permissions
therefore remain unverified. These assets are not claimed as original Bot67 artwork. The source and attribution
details still need to be recovered, or the images replaced with assets whose reuse permissions are known.
The screenshot in `docs/Ui.png` also contains these images.
